# Map Builder Core

You are building `notes/project-map.md` — a one-time index that lets future agents find relevant files without scanning the project.

## Input

You receive a path to a JSON file generated by `scripts/scan_project.py`.
The JSON is an array of objects:
```json
{ "path": "apps/api/routers/auth.py", "type": "python", "symbols": ["@post def login", "class AuthRouter"] }
```

## Steps

### 1. Read the structure file
Read the JSON at the path provided. Do not scan any directories yourself.

### 2. For each file entry
Read the actual file at `entry.path` (relative to project root).
Use `entry.symbols` as a reading hint — focus on those symbols to write a tight description.

Write one line per file in this format:
```
- apps/api/routers/auth.py — JWT login/register endpoints, depends on AuthService
```

Rules for descriptions:
- Max 12 words
- State what it does, not what it contains
- Name key dependencies or consumers if obvious
- Skip test files, config files, and `__init__.py` with no content

### 3. Write notes/project-map.md
Always overwrite the file completely — never append. This ensures the map stays in sync with the current scan.

Structure the output by top-level directory:

```markdown
# Project Map
_Generated from scripts/scan_project.py — re-run when structure changes._

## apps/api/
- apps/api/main.py — FastAPI app entry point, mounts all routers
...

## apps/web/
- apps/web/app/layout.tsx — root layout, sets global fonts and providers
...
```

### 4. Done
Report how many files were indexed and the output path.
Do not journal. Do not stamp anything. Just report.
